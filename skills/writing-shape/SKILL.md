# Writing Shape

Turn a fixed source pile into a coherent draft while preserving the source file.

1. Read the source material end-to-end and treat it as read-only.
2. Establish audience knowledge and the central claim the draft must earn.
3. Draft 2 or 3 materially different openings when the direction is not already settled. Pick the one that creates the clearest obligation for what comes next.
4. Build the article block by block. Each block should have one job and should either advance the argument, ground a concept, provide evidence/example, handle an objection, or create a necessary transition.
5. Choose format deliberately: prose for argument, lists for parallel items, tables for repeated comparable fields, quotes only when exact wording matters, code blocks for multi-line technical material.
6. Before every write, reread the current draft and preserve user edits. Edit only the selected block unless a broader rewrite is requested.
7. When the source lacks a necessary example or fact, name the gap rather than fabricating material.
8. Stop when the draft has fulfilled the opening's promise. Unused source fragments can remain unused.

Completion criterion: the draft reads as one coherent piece, every block earns its place, and no unsourced material was invented to fill gaps.
